# 13.0-rc6-plq110.2

修正诊断证据和报告可靠性，保留既有推送策略。

- 自查区分 Hook 注册、回调、保护/适配动作、暂不可执行和累计运行异常；解冻参数不兼容会提前排除。
- 广播入口仅称为可信投递请求，不宣称应用已收到或已发布通知；TCP 状态不宣称 FCM 协议健康。
- 连接时长使用单调时间；记录长采样空档与网络验证状态。

- 报告检查完成标记、退出码和超时；允许分享明确标注的部分结果。默认处理已知非目标应用包名及IP，可另选原始内容。

手机端升级需沿用原 debug 签名并重启使新 Hook 加载。整夜日志在本机固件上的文件写入及新界面需实机验证，构建和单测不能代替声音、震动及锁屏通知验收。

20秒默认窗口、GMS来源与目标校验、夜间重连策略和多用户限制保持原行为。
