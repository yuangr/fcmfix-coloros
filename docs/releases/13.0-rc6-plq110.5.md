# 13.0-rc6-plq110.5

针对一加 Ace 6 的 PLQ110_16.0.10.500(CN01)、Android 16/API 36 修复夜间深睡直接关闭网络的分支选择。该机凌晨的原厂电池记录显示 `useNetworkDisableWhiteList:false`，随后关闭移动数据，直到早晨亮屏才恢复；仅追加 GMS UID 无法阻止这条整机断网路径。

核对本机 Battery.apk 与 Oplus 框架后，新 Hook 在原生白名单功能、服务及 GMS/VPN 状态可用时选择原厂 UID 白名单模式。首次成功选择后，同一电池进程保持该模式，避免 VPN 重连时恢复路径切回另一种断网方式。保留睡眠待机优化、原厂状态机、网络恢复方法及错误回退。未知 OTA、一加 15 和其他版本不启用此新增分支。

电池名单和系统网络服务入口均保留原厂名单，并追加 GMS、当前 VPN 和始终开启 VPN 的 owner-user UID；不硬编码代理包名，不把全部 FCM 应用或 VPN 客户端加入整夜名单。VPN 读取失败时记录运行异常并保留已有 GMS 增补。原生调用非零返回值会进入自查运行异常，不能把 Hook 注册或改变选择器当作底层规则成功。

本地验证：25 个测试类、114 项测试通过；Debug/Release 构建和 Lint 均通过（各 0 错误、8 条既有警告）；APK 签名验证通过。本地 Debug 证书与手机现有 `.4` 证书不同，不能直接覆盖，未尝试卸载迁移。仓库不含私钥。

安装后需重启以加载系统框架和电池进程的新代码。当前仅完成固件/API 核对与本地构建验证，新增路径尚未在重启后的真实深睡或整夜场景验收。原厂网络异常模式、原生接口失败回退、夜间切换 VPN，以及其他应用经 VPN 的限流效果仍需实机确认。详细调用链和测试要求见[适配说明](../ace6-night-network-routing.md)。
