# 13.0-rc6-plq110.4

实机重启后日志可以写入，但远程配置监听仍未使停止诊断生效。应用现在在成功持久化配置后，通过经过原有包名与UID验证的有序广播发送完整配置快照。接收侧仅在身份验证通过后解析、验证类型，并在配置工作线程应用；不放宽FCM来源验证或后台窗口。

配置持久化递增版本号，工作线程只接受更高版本，防止未更新的远程缓存、重复或乱序广播覆盖已加载的新设置。远程偏好继续用于开机读取和监听；认证快照可在缓存读失败时生效。自查同时比较配置版本和诊断截止时间，避免旧的“放行数量相等”掩盖配置不同步。

新增回归覆盖旧缓存不覆盖停止诊断、重复/乱序、旧版迁移、版本类型校验及同步警告。日志写入、停止/开始和实际提醒仍需新Hook加载后验证。

实机还确认 ADB Root 受系统文件权限限制无法读取日志正文。报告追加认证系统框架查询的每文件末尾32KB，在后台线程由文件所属进程读取；明确标注截断，不修改文件权限或SELinux策略。模块内存日志每进程最多32768字符，避免增加附录后超出Binder传输预算。
